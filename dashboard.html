🚀 GETTING STARTED

SHOW
  1. Install the launcher (one time). Go to Settings → Setup and follow the instructions. Click Test connection until it turns green.
  2. Create Chrome profiles. Go to Profiles → Create Chrome Profile. One per Nike account. Sign into each.
  3. Add your cards. Go to Cards and save each card once. Multiple accounts can share one card.
  4. Set accounts. In Profiles, add each account — pick its Chrome profile, size, and card.
  5. Set the drop. Go to Drop — paste the URL, pick sizes, hit Randomly assign.
  6. Save config (Quick Launch above or the Save button on Drop page).
  7. Launch! Hit Launch All a few minutes early to warm Kasada, or use the scheduled timer.
