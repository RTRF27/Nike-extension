🚀 GETTING STARTED

SHOW
  1. Install the launcher (one time). Go to Settings → Setup and follow the instructions. Click Test connection until it turns green.
  2. Create Chrome profiles. Go to Profiles → Create Chrome Profile. One per Nike account. Sign into each.
  3. Add your cards. Go to Cards and save each card once. Multiple accounts can share one card.
  4. Set accounts. In Profiles, add each account — pick its Chrome profile, size, and card.
  5. Set the drop. Go to Drop — paste the URL, pick sizes, hit Randomly assign.
  6. Save config (Quick Launch above or the Save button on Drop page).
  7. Launch! Hit Launch All a few minutes early to warm Kasada, or use the scheduled timer.

MODE & TIMING

How each account checks out, when it submits, and the drop type

🛒 CHECKOUT METHOD

HOW EACH ACCOUNT COPS

Opens the SNKRS launch page, selects the size, and clicks Buy / Join Draw — letting Nike navigate to checkout the natural way. Slower by a moment, but avoids the “entry invalid” error you get from a pre-built checkout link. Recommended.

Jumps each account straight to its gs.nike.com checkout link (built below), skipping the launch page. Fastest, but Nike can reject the entry (“entry invalid”) if the link wasn’t established through the launch flow.

DROP TIME

SUBMIT TIMING

Open the pages yourself early (LAUNCH ALL) and let them sit — each account waits and clicks SUBMIT ORDER right on this time. Times auto-fill when you build direct URLs.

⏰ Also auto-open accounts
Optional. Auto-opens ⏰-armed accounts ~30s before drop. Leave OFF to open them yourself.

DROP TYPE

LEO / DAN
Drop type

Raffle drops stay open ~20 min and aren't won on speed — the bot fills carefully and adds a small random human delay before submitting (spreads accounts, looks less bot-like).

First-come-first-served — the bot strips its settling delays and submits with millisecond precision: tabs waiting for the drop submit on the dot; a tab opened after drop time submits immediately.

🪟 Small tiled windows
Open each profile as a small window, tiled across your screen, instead of full-size. The extension resizes each window itself, so it works even for profiles that are already running.
📐 Auto-fit to screen (no overlap)
Sizes every window so they all fit side by side with nothing hidden behind anything. Turn OFF to set the size yourself.
× px
See how the windows will tile on your screen.

Chrome won't render a window narrower than 500px, so that's the hard limit on columns. Windows that can't fit are left at Chrome's default size rather than stacked invisibly on top of each other.

🧩 Load extension at launch
For profiles that keep losing the extension: load it fresh each launch. NOTE: Chrome only applies this to the profile that cold-starts the browser — if Chrome is already open, other profiles ignore it. Test whether it reaches all your profiles.
