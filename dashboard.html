🚀 GETTING STARTED — HOW TO RUN A DROP

SHOW

Follow these once per machine, then steps 4–7 for every drop.

  1. Install the launcher (one time). The dashboard can’t open other Chrome profiles by itself. Install the native helper from the native-host/ folder, then click Test launcher connection below the accounts. It should turn green.
  2. Create a Chrome profile per Nike account. Use Create Chrome Profile (right column). Each click opens a fresh profile on the Nike SG login page — sign into one Nike account there. Repeat for every account.
  3. Create your cards. In Card Profiles, add each card once (nickname + details). Profiles hold no saved cards, so the bot fills one per entry.
  4. Add accounts. Each account row = one Chrome profile. Pick the profile, give it a label, set its size, and choose which saved card it uses from the 💳 Card dropdown (several accounts can share one card).
  5. Set the drop. Paste the product URL and pick your size pool in Drop Details. Hit 🎲 Randomly assign to deal a size to each account.
  6. Save. Click Save central config so the launcher writes the shared config every profile reads at drop time.
  7. Pre-warm (optional but recommended). A few minutes before the drop, click 🚀 Launch all now to open every profile so Kasada warms up. Profiles that aren’t fully set up just open to the SNKRS feed; fully-configured ones go straight to the product.
  8. Drop time. Either let ⏰ Scheduled auto-launch open the ⏰-marked accounts automatically, or click 🚀 Launch all now yourself. Watch the live status badge on each row, and verify wins in Order Checker afterwards.
