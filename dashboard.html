ONE-TIME LAUNCHER SETUP

  1. Make sure Node.js is installed (node --version in a terminal).
  2. In the native-host/ folder of this extension, run the installer:
    • Windows: double-click install-windows.bat
    • macOS / Linux: ./install-unix.sh in a terminal
  3. Install/reload this extension in chrome://extensions (Developer mode → Load unpacked). Its ID is fixed to kopeofjmoelfkdcmfcenkedojhoaolfb.
  4. Come back here and click Test launcher connection. It should turn green.

Why a helper? Chrome extensions are sandboxed and cannot open other Chrome profiles by themselves. This tiny local helper is what actually runs chrome --profile-directory=… for each account.
